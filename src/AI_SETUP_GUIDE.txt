ORBYTE DUAL-PROVIDER SETUP (RUNPOD FOR OCR + GEMINI FOR TEXT ANALYSIS)

Setup Architecture:
1. Receipt Slips Analysis (OCR): Handled by your Runpod Serverless endpoint.
2. WhatsApp Order Message Parsing (Text Analysis): Handled by Google Gemini API.

Quick Setup Instructions:
1. Open `.env` in this folder.
2. Ensure OCR is set to Runpod:
   OCR_PROVIDER=runpod
   RUNPOD_API_KEY=rpa_...
   RUNPOD_ENDPOINT_ID=6tzygt...
3. Add your Gemini API key for message/order text parsing:
   GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE
   MESSAGE_AI_PROVIDER=gemini
   GEMINI_MODEL=gemini-1.5-flash
4. Save `.env`.
5. Run the server using `run_orbyte.bat` or `python -m uvicorn main:app --reload --port 8000`.
6. Go to http://127.0.0.1:8000.
