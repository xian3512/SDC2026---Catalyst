ORBYTE BACKEND CONNECTION FIX

1. Extract these files into your existing orbyte_role3_starter folder and replace matching code files.
2. Do NOT replace your .env or data/*.db files.
3. Double-click run_orbyte.bat, or run `python -m uvicorn main:app --reload --port 8000` in the project folder.
4. Keep the terminal window open.
5. Open http://127.0.0.1:8000 (do not open the HTML file directly for the normal workflow).
6. Check http://127.0.0.1:8000/health; it should show JSON with "ok": true.

If startup fails, read the first error printed in the terminal. If port 8000 is already in use, stop the old Uvicorn process before restarting.
